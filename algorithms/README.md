# Algorithms

Small Java drills for graph, list, and other LeetCode-style interviews. Run `./gradlew test`.

## Graph

- **representation** — adjacency list vs matrix.
- **bfs** — queue, visited set, fewest hops.
- **dfs** — recursion and an explicit stack.
- **cycle** — directed cycle with DFS colours.
- **topological** — Kahn's order; empty when a cycle remains.

## Knowledge graph

Patterns used for fraud rings, influence, and a few hops of retrieval next to a language model.

- **components** — Union-Find groups accounts that share a link.
- **bipartite** — project accounts that share a device or other identifier.
- **centrality** — degree and a short PageRank; the hub ranks highest.
- **neighbourhood** — breadth-first search stopped at depth 1 or 2.

## Linked list

A `ListNode` (`value`, `next`), not `java.util.LinkedList`.

- **reverse** — flip pointers, iterative and recursive.
- **cycle** — Floyd's slow and fast pointers.
- **merge** — splice two sorted lists.

## Also

- **tree** — max depth, invert, level-order BFS.
- **two_pointers** — sorted two-sum and a unique-character window.
- **binary_search** — first occurrence and search in a rotated array.
- **stack** — matching brackets and next greater element.
