# Date and time

`java.time` samples. Run `./gradlew test`.

- **date** — `LocalDate` and `Period`.
- **time** — `LocalTime` and `LocalDateTime`.
- **timezone** — `ZoneId`, `ZonedDateTime`, `OffsetDateTime`.
- **clock** — a fixed `Clock` instead of the system clock.
- **duration** — elapsed time between two instants.
- **formatting** — `DateTimeFormatter` parse and format.
