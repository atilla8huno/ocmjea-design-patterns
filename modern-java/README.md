# Modern Java

Java 9–21 features that turn up in interviews. Run `./gradlew test`.

- **factories** — `List.of`, `Set.of`, `Map.of`.
- **var_local** — local `var`.
- **strings** — text blocks and `formatted`.
- **records** — compact data types with value equality.
- **pattern_matching** — `instanceof` with a binding.
- **switch_expressions** — arrow cases and `yield`.
- **sealed** — a closed type hierarchy.
- **stream_helpers** — newer Stream methods.
- **virtual_threads** — `Thread.startVirtualThread`.
