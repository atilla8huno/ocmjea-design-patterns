# Collections

Each package is one collection used on a small algorithm problem. Run `./gradlew test`.

- **list / mutable_list** — index lookup, binary search, merge two sorted lists.
- **set / mutable_set / linked_set / sorted_set** — membership, first duplicate, arrival order, range queries.
- **map / mutable_map / linked_map / sorted_map** — lookup tables, two-sum, LRU cache, floor/range keys.
- **array / primitive_arrays** — in-place reverse, prefix sums.
- **array_deque** — BFS hops and palindrome checks.
- **priority_queue** — top-k and urgent-task order.
- **sequence / operations** — lazy first-match and word frequency.
- **array_blocking_queue / linked_blocking_queue** — bounded producer-consumer and poison-pill shutdown.
- **delay_queue** — release a job only when it is due.
- **concurrent_hash_map / concurrent_linked_queue / concurrent_skip_list_map** — cache init, lock-free FIFO, live scoreboard.
- **copy_on_write_array_list** — snapshot iteration while listeners are added.
