# Spring

Common Spring Boot annotations. Run `./gradlew test`.

- **injection** — `@Component`, `@Service`, `@Repository`, `@Autowired`, `@Primary`, `@Qualifier`.
- **configuration** — `@Configuration`, `@Bean`, `@Value`, `@ConfigurationProperties`, `@Profile`.
- **web** — `@RestController` and HTTP mappings, path, query and header parameters.
- **validation** — Jakarta `@Valid` on a request body.
- **exception** — `@RestControllerAdvice` and `@ExceptionHandler`.
- **lifecycle** — `@PostConstruct` and `@PreDestroy`.
- **async_scheduling** — `@Async` and `@Scheduled`.
