# Design patterns

GoF samples. One package per pattern. Run `./gradlew test`.

## Creational

- **Factory Method** — create implementations through one interface.
- **Abstract Factory** — create related families of objects.
- **Builder** — build a complex object step by step.
- **Prototype** — copy an existing object.
- **Singleton** — one shared instance.

## Structural

- **Adapter** — make one interface look like another.
- **Bridge** — split an abstraction from its implementation.
- **Composite** — treat a leaf and a tree the same way.
- **Decorator** — add behaviour by wrapping.
- **Facade** — hide a subsystem behind a simple API.
- **Flyweight** — share repeated intrinsic state.
- **Proxy** — control access to another object.

## Behavioural

- **Chain of Responsibility** — pass a request along handlers.
- **Command** — turn an action into an object.
- **Interpreter** — evaluate a small grammar.
- **Iterator** — walk a collection without exposing storage.
- **Mediator** — route communication through one object.
- **Memento** — capture and restore state.
- **Observer** — notify subscribers of changes.
- **State** — change behaviour by swapping a state object.
- **Strategy** — swap algorithms behind one contract.
- **Template Method** — fix the steps, override some of them.
- **Visitor** — add an operation without changing the elements.
