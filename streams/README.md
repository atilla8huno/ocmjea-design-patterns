# Streams

The Java Stream API, one package per stage. Run `./gradlew test`.

- **creation** — `of`, `iterate`, collections, arrays.
- **intermediate** — `filter`, `map`, `flatMap`, `distinct`, `sorted`, `limit`.
- **terminal** — `forEach`, `reduce`, `count`, `findFirst`, `anyMatch`.
- **collectors** — `toList`, `groupingBy`, `joining`, `partitioningBy`.
- **primitives** — `IntStream` and friends.
- **optional** — empty vs present, `map`, `orElse`.
- **parallel** — `parallelStream` for a simple reduction.
